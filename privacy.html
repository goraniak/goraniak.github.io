개인정보처리방침

시행일: 2026년 10월 12일

Goraniak(이하 "서비스")은 이용자의 개인정보를 중요하게 여기며, 관련 법령을 준수합니다. 이 방침은 서비스가 어떤 정보를 수집하고 어떻게 이용·보관·삭제하는지 설명합니다.

1. 수집하는 정보

이용자가 Google 계정으로 로그인하면 서비스는 Google로부터 다음 정보를 받습니다.

  • 이메일 주소
  • 이름
  • 프로필 사진

서비스는 위 정보 외의 Google 계정 정보에 접근하지 않습니다.

2. 이용 목적

  • 로그인 및 이용자 구분
  • 서비스 화면에 이용자 이름 표시
  • 서비스 관련 문의에 대한 응답

수집한 정보는 위 목적 외에는 사용하지 않으며, 광고 목적으로 사용하지 않습니다.

3. 보관 및 파기

  • 서비스는 받은 정보를 로그인 확인에만 사용하며, 별도의 서버나 데이터베이스에 저장하지 않습니다.
  • 로그아웃하거나 접근 권한을 해제하면 서비스는 더 이상 해당 정보에 접근하지 않습니다.

4. 제3자 제공

서비스는 이용자의 정보를 제3자에게 판매하거나 제공하지 않습니다. 다만 법령에 따라 요구되는 경우는 예외로 합니다.

5. Google API 데이터 처리

서비스가 Google API로부터 받은 정보의 사용 및 다른 앱으로의 전송은 Google API 서비스 사용자 데이터 정책(제한적 사용 요건 포함)을 준수합니다.
